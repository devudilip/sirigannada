#     ಪುಡಿ ಪುಡಿಗೈದನು→ಪುಡಿಪುಡಿಗೈದನು; ಬೆಳೆಯುತ್ತ ಹೋದನು→ಬಳೆಯುತ್ತ ಹೋದನು; ಪ್ರಯೋಜನವನ್ನು ಅರಿತ ಈ→ಪ್ರಯೋಜನವನ್ನು ಅರಿಯದ ಈ; ತನ್ನ ಕೈ ಕೊಡಲಿಯನ್ನು→ತನ್ನ ಕೈಕೊಡಲಿಯನ್ನು;
#   scan 29: ರಾಜಭಿಲಾಷೆಯಿಂದ→ರಾಜಾಭಿಲಾಷೆಯಿಂದ; ನೆಲ್ಲು ಹುಲ್ಲಿನಂತೆ ಕೊಟ್ಟು ಬಿಟ್ಟು→ನೆಲ್ಲುಹುಲ್ಲಿನಂತೆ ಕೊಯ್ದುಬಿಟ್ಟು; ಯುದ್ಧ ಕೊಡುವುದು→ಯುದ್ಧಕೊಡುವುದು;
#     ಹೇಳಿದನು. ಮಾತು ರಾಜನಿಗೆ→ಹೇಳಿದನು. ಈ ಮಾತು ರಾಜನಿಗೆ; ಹೊರಡಿಸುವಂತೆ - ಅವನು→ಹೊರಡಿಸುವಂತೆ—ಅವನು; ಶತ್ರು ಹಸ್ತದಿಂದ→ಶತ್ರುಹಸ್ತದಿಂದ;
#     ಎಂದು ರಾಮದೇವನ ಅಳಿಯನ→ಎಂದು ರಾಮದೇವನು ಅಳಿಯನ; ಯಾವ ಕಾರಣದಿಂದಲೂ ಸಮ್ಮತವಾಗಲಿಲ್ಲ→ಯಾವ ಕಾರಣದಿಂದಲೊ ಸಮ್ಮತವಾಗಲಿಲ್ಲ; ಯುದ್ಧ ಮಾಡಲೇಬೇಕೆಂದು→ಯುದ್ಧಮಾಡಲೇಬೇಕೆಂದು;
#   scan 30: ರಾಮದೇವನ ಸಾಕೂತದೃಷ್ಟಿಯಿಂದ→ರಾಮದೇವನು ಸಾಕೂತದೃಷ್ಟಿಯಿಂದ; ಪ್ರಾಣ ವಲ್ಲಭನ→ಪ್ರಾಣವಲ್ಲಭನ; ಬಿದ್ದು ಹೋದನೆಂಬ→ಬಿದ್ದುಹೋದನೆಂಬ; ರಕ್ತ ಸೇಚನದಿಂದ→ರಕ್ತಸೇಚನದಿಂದ;
#   scan 31: ಒಂದರೊಳಗೊಂದಾಗಿ→ಒಂದರ ಒಳಗೊಂದಾಗಿ; ನಿದ್ದೆ ಹೋಗಬಹುದಿತ್ತು→ನಿದ್ದೆಹೋಗಬಹುದಿತ್ತು; ಕಲಕಲ - ಇವೆಲ್ಲಾ→ಕಲಕಲ—ಇವೆಲ್ಲಾ;
#     ಉತ್ಸಾಹಗೊಳಿಸುವ ಶತ್ರುಚಲನೆಯನ್ನು→ಉತ್ಸಾಹಗೊಳಿಸುತ್ತ ಶತ್ರುಚಲನೆಯನ್ನು; ಸುಖವಾಗಿ ನಿದ್ದೆ ಹೋಗುತ್ತಿದ್ದರು→ಸುಖವಾಗಿ ನಿದ್ದೆಹೋಗುತ್ತಿದ್ದರು;
#   scan 32: ಉಚ್ಚ ಪದವಿಯನ್ನು→ಉಚ್ಚಪದವಿಯನ್ನು; ಹಾಸು ಹೊಕ್ಕಾಗಿದ್ದುವು→ಹಾಸುಹೊಕ್ಕಾಗಿದ್ದುವು; ತೆವೀರಿತು→ತೋರಿತು;
#   scan 33: ಇಳಿಸಿರುವೆಯ?→ಇಳಿಸಿರುವೆಯೋ?; ಮರೆಯಲಾರೆನು, ಅರಮನೆಯನ್ನು ಕಾಯುವಷ್ಟು ಕೈ ತುಂಬಾ→ಮರೆಯಲಾರೆನು. ಅರಮನೆಯನ್ನು ಕಾಯುವಷ್ಟು ಕೈತುಂಬಾ;
#     ಎಡಕ್ಕೆ ತಿರುಗಿದರೆ-→ಎಡಕ್ಕೆ ತಿರುಗಿದರೆ—; ಸುತ್ತು ಮುತ್ತಲು→ಸುತ್ತುಮುತ್ತಲು; ಹಿತ್ತೊಲದಿಂದ→ಹಿಲ್ಲೋಲದಿಂದ;
#   scan 34: “ಧಿಕ್! ಧಿಕ್!”→“ಧಿಗ್! ಧಿಕ್!”; ಕೆಟ್ಟು ಹೋಗುವುದು→ಕೆಟ್ಟುಹೋಗುವುದು; ಸ್ತ್ರೀ ಧ್ವನಿಯು→ಸ್ತ್ರೀಧ್ವನಿಯು; ಆಗಂತುಕ ಘಾತವನ್ನು→ಆಗಂತುಕನು ಘಾತವನ್ನು;
#     ಬಿದ್ದು ಬಿಟ್ಟನು→ಬಿದ್ದುಬಿಟ್ಟನು;
#   scan 35: ಕೃಷ್ಣ ರಾಜನು ಉಜ್ವಲ→ಕೃಷ್ಣರಾಜನು ಉಜ್ವಲ; ತಂದುಬಿಟ್ಟಿಯಲ್ಲ→ತಂದುಬಿಟ್ಟೆಯಲ್ಲ; ಶರಪುಷ್ಪವೇ→ಶಿರಪುಷ್ಪವೇ;
#   scan 36: ಸಹಸ್ರಬಿಂಬವಾಗಿ ಬೆಳಗುತ್ತಿದ್ದನು→ಸಹಸ್ರಬಿಂಬನಾಗಿ ಬೆಳಗುತಿದ್ದನು; ಮನುಷ್ಯ ಸಂಚಾರವಿರಲಿಲ್ಲ→ಮನುಷ್ಯಸಂಚಾರವಿರಲಿಲ್ಲ;
#   scan 37: ಸ್ತಬ್ದವಾಯಿತು→ಸ್ತಬ್ಧವಾಯಿತು; ಗೋಡೆಯವರೆಗೆ→ಗೋಡೆಯ ವರೆಗೆ; ಕೊರಳನ್ನು ಇಲ್ಲಿ ನೋಡಿದನು→ಕೊರಳನ್ನು ನಿಲ್ಕಿ ನೋಡಿದನು; ನಿಲ್ಲದ ಪೋಗುವೆ→ನಿಲ್ಲದೆ ಪೋಗುವೆ;
#     ಇಣಿಕಿ ನೋಡಿದನು, ಉಪ್ಪರಿಗೆಯ→ಇಣಿಕಿ ನೋಡಿದನು. ಉಪ್ಪರಿಗೆಯ;
#   scan 38: ರಮಣಿಯ ಹಾಡು ಅಂತು→ರಮಣಿಯ ಹಾಡು ತೀರಿತು; ಸ್ವಪ್ನ ಸಾಮ್ರಾಜ್ಯದ→ಸ್ವಪ್ನಸಾಮ್ರಾಜ್ಯದ; ಮಂದಸ್ಮಿತವು ಅಡಗಿತ್ತು, ಹೊಳೆ ಹೊಳೆವ→ಮಂದಸ್ಮಿತವು ಅಡಗಿತ್ತು. ಹೊಳೆಹೊಳೆವ;
#     ಮೋಹನಶಕ್ತಿಯೂ ನೋಡ ಸಿಕ್ಕದು→ಮೋಹನಶಕ್ತಿಯೂ ನೋಡಸಿಕ್ಕದು; ಸೆಳೆದುಬಿಡುವುದು ಎಷ್ಟು→ಸೆಳೆದುಬಿಡುವುದು. ಎಷ್ಟು; ಉಷ್ಣ ಸ್ಪರ್ಶದಿಂದ→ಉಷ್ಣಸ್ಪರ್ಶದಿಂದ;
#   scan 39: ಇರುಳೆಲ್ಲಾ -→ಇರುಳೆಲ್ಲಾ—; ಹೊರ ಚಾಚಿ→ಹೊರಚಾಚಿ;
#   scan 40: ಕೈ ಸನ್ನೆ ಮಾಡಿದಳು→ಕೈಸನ್ನೆ ಮಾಡಿದಳು; ಶಿರೀಶಪುಷ್ಪ ಸದೃಶವಾದ→ಶಿರೀಶಪುಷ್ಪಸದೃಶವಾದ; ತಂದೆ ಹೀಗಿಸುವುದು→ತಂದೆ ಹೀನಿಸುವುದು; ಒಮ್ಮೆ ನಿಶ್ಚಯಿಸಿ→ಒಮ್ಮೆ ನಿಶ್ಚೈಸಿ;
#   scan 41: ಹೇಳಿಬಿಟ್ಟಳು, “ನವಮಿ→ಹೇಳಿಬಿಟ್ಟಳು. “ನವಮಿ; ಒತ್ತಿ ಹೇಳಿದನು→ಒತ್ತಿ ಕೇಳಿದನು; ಈ ಕಥಾ ಕಾಲದಲ್ಲಿ→ಈ ಕಥಾಕಾಲದಲ್ಲಿ; ಜಯಸಿಂಹನು ಡಿಲ್ಲಿಯ→ಜಯಸಿಂಹನು ಢಿಲ್ಲಿಯ;
#     ಮಹಾರಾಷ್ಟ್ರ ಸಾಮ್ರಾಜ್ಯವನ್ನು→ಮಹಾರಾಷ್ಟ್ರಸಾಮ್ರಾಜ್ಯವನ್ನು;
#   scan 42: ಶೀರ್ಷೋದಯವಾಗುವಂತೆ→ಶಿರ್ಷೋದಯವಾಗುವಂತೆ; ಆಪತ್ತು ವಿಪತ್ತುಗಳೆ ಶಿವಾಜಿಯ ಸಾಹಸರ್ಯಗಳಿಗೆ→ಆಪತ್ತುವಿಪತ್ತುಗಳೇ ಶಿವಾಜಿಯ ಸಾಹಸಶೌರ್ಯಗಳಿಗೆ;
#     ಕಷ್ಟ ಸಂಕಷ್ಟಗಳು→ಕಷ್ಟಸಂಕಷ್ಟಗಳು; ಆಹ್ವಾನ ಪತ್ರವನ್ನು→ಆಹ್ವಾನಪತ್ರವನ್ನು; ಜ್ಯೇಷ್ಠ ಪುತ್ರನಾದ→ಜ್ಯೇಷ್ಠಪುತ್ರನಾದ;
#   scan 43: ಮಾತೆತ್ತಲಿಲ್ಲ. ಸಿಂಹನು ಎತ್ತಿದ→ಮಾತೆತ್ತಲಿಲ್ಲ. ಬಳಿಕ ರಾಜಸಿಂಹನು ಎತ್ತಿದ;
#   scan 44: ವಿಚಾರಮಾಡಿರಲಿಲ್ಲ, ನೀನು→ವಿಚಾರಮಾಡಿರಲಿಲ್ಲ. ನೀನು; ರಾಜಪತ್ನಿ ಯಾಗುವುದಕ್ಕಿಂತಲೂ→ರಾಜಪತ್ನಿಯಾಗುವುದಕ್ಕಿಂತಲೂ; ಮತ್ತೊಂದಿರುವದೇ→ಮತ್ತೊಂದಿರುವುದೇ;
#     ಅಧಿಕ ತರವಾದ→ಅಧಿಕತರವಾದ; ಸಾಮಾನ್ಯ ಪುರುಷರಿಗೆ→ಸಾಮಾನ್ಯಪುರುಷರಿಗೆ; ತಂದಿಕ್ಕ ಬೇಡ→ತಂದಿಕ್ಕಬೇಡ; ಹೆಣ್ಣು ಕೊಟ್ಟ→ಹೆಣ್ಣುಕೊಟ್ಟ; ಸಲೀಮನ ಪತ್ನಿಯಾಗಿ→ಸೇಲಿಮನ ಪತ್ನಿಯಾಗಿ;
#   scan 45: ಕೈಯೊಡ್ಡಿದ ನಮ್ಮ→ಕೈಯೊಡ್ಡುವ ನಮ್ಮ; ಹೇಳುವೆನು, ನಾನು ಬಡ→ಹೇಳುವೆನು. ನಾನು ಬಡ; ಕಂಡವರನ್ನು ಕೈ ಹಿಡಿದು→ಕಂಡವರನ್ನು ಕೈಹಿಡಿದು;
#     ಭವಾನಿಭಕ್ತನಾದ - ರಾಮದಾಸ→ಭವಾನಿಭಕ್ತನಾದ ರಾಮದಾಸ;
#   scan 46: ಶಹಜಹಾನ್ಬಾದ್→ಶಹಾಜಹಾನ್ಬಾದ್; ಶಾಲಿ ಸಮೃದ್ಧವಾದ→ಶಾಲಿಸಮೃದ್ಧವಾದ; ವೇಷ್ಟಿಸಿತ್ತು- ೭→ವೇಷ್ಟಿಸಿತ್ತು—೭; ಹುಲ್ಲು ಗುಡಿಸಲುಗಳು→ಹುಲ್ಲುಗುಡಿಸಲುಗಳು;
#     ದೀಕ್ಷಾ ಗುರುವಾದ→ದೀಕ್ಷಾಗುರುವಾದ;
#   scan 47: ಕುದಿದನು. ಶಿವಾಜಿಯೂ→ಕುದಿದನು. ಬಳಿಕ ಶಿವಾಜಿಯೂ; ಪ್ರಸ್ಥಾನದ→ಪ್ರಸ್ತಾನದ; ನೂರಾರು ಮಿನಾರುಗಳು→ನೂರಾರು ಮಿನಾರತುಗಳು;
#     ಸಮೀಪಸ್ಥವಾದಂತೆ ತೋರಿತು, ಜನಸಂದೋಹವು→ಸಮೀಪಸ್ಥವಾದಂತೆ ತೋರಿತು. ಜನಸಂದೋಹವು; ಚಾಂದಣಿ ಚೌಕಕ್ಕೆ→ಚಾಂದಣೀ ಚೌಕಕ್ಕೆ; ಜ್ಯೋತಿಷ್ಯರು→ಜ್ಯೋತಿಷ್ಕರು;
#   scan 48: ಜನ ಸಂದೋಹದೊಡನೆ→ಜನಸಂದೋಹದೊಡನೆ; ಇನ್ಯಾವ ಕಾರಣದಿಂದಲೂ→ಇನ್ಯಾವ ಕಾರಣದಿಂದಲೊ; ವಸ್ತ್ರ ಶಾಲೆಗಳು→ವಸ್ತ್ರಶಾಲೆಗಳು;
#   scan 49: ಬೆರಗುಗೊಳಿಸಬೇಕೆಂದು ಬಾದಶಹನ→ಬೆರಗುಗೊಳಿಸಬೇಕೆಂದು ಬಾದಶಹನು; ಮೂರು ವೇದಿಕೆಗಳು, ಮಾಂಡಲಿಕರೂ→ಮೂರು ವೇದಿಕೆಗಳು. ಮಾಂಡಲಿಕರೂ;
#     ಜಾತಿ ಸುವರ್ಣ ನಿರ್ಮಿತವಾದ→ಜಾತಿ ಸುವರ್ಣನಿರ್ಮಿತವಾದ; ದ್ವಾದಶಕಾಂಚನಸ್ತಂಭಾಕೃತವಾದ→ದ್ವಾದಶಕಾಂಚನಸ್ತಂಭಾದೃತವಾದ;
#     ಅಸ್ತ್ರಶಸ್ತ್ರಗಳನ್ನೂ ಕೊಟ್ಟು→ಅಸ್ತ್ರಶಸ್ತ್ರಗಳನ್ನೂ ತೊಟ್ಟು;
#   scan 50: “ಅಮ್ ಖಾಸ್ ಖಾನೆಯ”→“ಆಮ್ ಖಾಸ್ ಖಾನೆಯ”; ಸೌಭಾಗ್ಯ ಸೌರಂಭವನ್ನು→ಸೌಭಾಗ್ಯಸೌರಂಭವನ್ನು; ಸುವರ್ಣ ವೇದಿಕೆಯ ಮೇಲಿದ್ದ→ಸುವರ್ಣವೇದಿಕೆಯ ಮೇಲಿದ್ದ;
#     ಚಿಂತಿಸಿದನು. ರಾಜಸಿಂಹನೊಡನೆ→ಚಿಂತಿಸಿದನು. ಬಳಿಕ ರಾಜಸಿಂಹನೊಡನೆ; ಕೆಟ್ಟು ಹೋಗುವುದೆಂಬುದು→ಕೆಟ್ಟುಹೋಗುವುದೆಂಬುದು;
#   scan 51: ಸುವರ್ಣ ವೇದಿಕೆಯ ಮೂಲೆಯಲ್ಲಿ→ಸುವರ್ಣವೇದಿಕೆಯ ಮೂಲೆಯಲ್ಲಿ;

#   - ASCII "|" / "||" normalised away; verse numbers normalised to a Kannada numeral at the end
#     of the last line; suchane (3-line) kept as its own block prefixed by ಸೂಚನೆ
#   - mid-line dandas (two padas on one source line) split so each shatpadi is six lines
#   - conversion glitch ಮೆಯೊೈಳಿರದೆ → ಮೆಯೊಳಿರದೆ (4.36; two vowel signs, ಳ lost)
#   - leftover "||17|||" / "||54|| |" style markers stripped; unnumbered verses given the
#     sequential number the surrounding verses imply (2.23 and 2.24 had no source number)
#   - stray "!" at three pada ends (2.66, 2.67, 3.16) dropped; they are not verse text
#   - 4.25 and 4.56: one source line held two padas with no danda; split to restore six lines
